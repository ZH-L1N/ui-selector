## MINOR — all 3 accepted

- `spikes/out/` was never created → `mkdirSync(…, { recursive: true })`.
- `'preferCurrentTab' in navigator.mediaDevices.getSupportedConstraints?.() ?? {}`
  parses as `('preferCurrentTab' in undefined) ?? {}` because `in` binds tighter than
  `??` → constraints bound to a local first.
- `rule instanceof CSSLayerBlockRule` throws `ReferenceError` where the constructor is
  absent → all CSSOM rule types feature-detected through `globalThis`.
