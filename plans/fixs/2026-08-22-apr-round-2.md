## MAJOR — all 14 accepted

- **Shadow DOM was undefined behaviour.** `TreeWalker` does not cross a shadow root, so
  open-root content was silently absent and indistinguishable from an empty subtree.
  Spec now states the boundary explicitly and a `shadow-boundary` omission is recorded;
  a fixture with open and closed roots tests it.
- **Attribute tables were never enumerated**, so an implementation could allowlist
  `poster`, `action`, `formaction`, or `srcset` without routing it through the scheme
  guard. Both lists are now closed, with a documented reason for every exclusion, plus
  an `it.each` matrix of every allowed URL attribute against 8 schemes.
- **Custom-property ordering was still wrong.** Self-before-ancestor fixed the trivial
  case but not the real one: a high-specificity `--brand` on `html` must lose to a
  low-specificity one on a nearer ancestor. `customProperties` now carries
  `ancestorDepth`, `important`, and source-order indices; depth dominates specificity;
  `tokens-override.html` is built specifically to catch the inversion.
- **CSSOM walk was incomplete and its condition tracking was lossy.** `@import` is now
  traversed (with the same cross-origin guard), `@container`/`@scope` are skipped with a
  new `unsupported-at-rule` omission, and conditions are a **stack** rebuilt per level
  instead of one mutable string that a nested `@supports` would overwrite. Cascade
  layers are traversed but their *order* is explicitly not modelled.
- **The guarantee itself was overstated.** Spec §6.2 now says plainly that Deep reports
  rules *observed to match* — with specificity, source sheet, and an `important` list —
  and does **not** resolve the cascade. Consumers get evidence, not a verdict.
  Reimplementing the CSS cascade in a bookmarklet is not an MVP.
- **Containing block ≠ stacking context.** The field was misnamed and the algorithm
  described neither thing correctly. Renamed `nearestStackingContextSelector`, with the
  three different real containing-block rules spelled out as the reason the old name was
  wrong. Spec §6.1 amended to match.
- **A test asserted a stacking entry the fixture could not justify** (`length > 0` on a
  grid fixture with no positioned ancestor), which would have forced an implementation
  to invent one. Now asserts the empty stack, with a separate fixture that has a real
  boundary.
- **The deterministic crop test could have asserted on a blank frame.**
  `captureStream(1)` plus two `requestAnimationFrame`s guarantees neither metadata nor a
  delivered frame. Now paints on a rAF loop at 30fps and samples a pixel, so a
  correctly-sized blank crop fails.
- **The cleanup test proved nothing** — it called the success path and caught nothing.
  Now forces a throw inside the crop by arming `getContext`, then asserts every track
  ended.
- **Screenshot support contract contradicted itself.** Spec said Firefox/Safari are
  disabled with `unsupported-browser`; the implementation degraded instead. Resolved in
  favour of degradation, stated once in spec §7 and §9: support depends on
  `getDisplayMedia` existing and nothing else, `preferCurrentTab` is a hint,
  `getSupportedConstraints()` is a track-constraint probe and never a gate. Tests
  rewritten to match, plus a `user-declined` case.
- `reuseExistingServer: true` on all three ports was a false-pass generator → disabled
  in CI, and `global-setup` now fetches from each server and asserts our fixtures and
  our bundle are what is being served.
- **Storage instrumentation hooked only `setItem`**, so a read, `removeItem`, `clear`,
  a cookie write, or an IndexedDB open would have passed silently. Now wraps all of
  those plus Cache Storage, runs a full capture rather than just the dialog, and asserts
  the stronger invariant: **no storage API is called at all**.
- **Deep assets had no schema** — no collection algorithm, cap, or cross-origin rule.
  Now a typed `Asset` with four sources, mandatory `reducedUrl`, `blocked-scheme` on
  `data:`/`blob:`, and a test asserting the seeded data-URL never appears.
- Task 10's unit test needed a DOM but declared no environment, and `makeContext` was
  used without ever being produced → environment declared, helper added to Task 2's
  interfaces.

## MINOR — all 5 accepted

- Text cap stopped one character early and materialized whole text nodes before
  slicing → slice-before-normalize with exact-boundary accounting and a boundary test.
- `tests/server.mjs`: `decodeURIComponent` moved inside a guard returning 400;
  containment via `realpath` + `relative` instead of a lexical `startsWith` that a
  symlink defeats; MIME map extended.
- Nested `@media`/`@supports` conjunction — same fix as the condition stack above.
- The "offline CI" claim vs `npx playwright install` → browser provisioning is now
  stated as a bootstrap prerequisite; the offline guarantee covers the test run.
- **Scope.** Codex judged the plan over-built for an MVP and recommended deferring Deep
  mode and the font heuristic. Resolved as follows:
  - The canvas `measureText` font heuristic is **cut**. That is a correctness fix, not a
    scope cut: the field could report "this family did not render" when it did, and a
    field that can lie is worse than an absent one.
  - **Deep mode is retained at full scope by user decision** (2026-08-22). It was in the
    approved spec, so deferring it was never mine to decide. The correctness burden that
    made it expensive is addressed by narrowing the *guarantee* — Deep reports rules
    observed to match, not a resolved cascade — rather than by removing the feature. The
    remaining Task 11 cost is real work with real tests, and it is accepted knowingly.

## Convergence note

Round 1: 19 findings. Round 2: 22. Not converging — but the two classes behave
differently and that distinction drives what round 3 should do.

- **Privacy findings are converging.** Round 1 found two holes, round 2 found the root
  gap in the fix. That is a bounded surface being swept properly.
- **CSS-correctness findings were diverging**, because CSS is unbounded: `@container`,
  `@scope`, layers, `!important`, nesting, proximity. Chasing them turns a bookmarklet
  into a cascade reimplementation. That class is now closed by *narrowing the stated
  guarantee* rather than by implementing more of CSS — which is the option codex itself
  offered.

Recommendation: round 3 is the last, and scoped narrowly to verifying the round-2 fixes
and auditing whether the narrowed contracts are honestly stated — not hunting new CSS
edge cases. Then implement.
